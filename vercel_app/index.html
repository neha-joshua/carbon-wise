03 — METHOD & LIMITS

Useful decisions start
with honest boundaries.

This Vercel edition is a new browser-based prototype. It is not the existing Streamlit dashboard, and it does not yet include the full evidence room, NSGA-II optimizer or persistent audit records.

01 / USER INPUT

Bring evidence you control

Each portfolio result is calculated from the values in the CSV you upload. Missing or invalid planning values are excluded and reported.

02 / ALLOCATION RULE

See how priorities change the plan

The shortlist ranks projects by a weighted, dataset-relative score, then fits them under your budget. This is a transparent heuristic, not a global optimum.

03 / PHOTO SIGNAL

Pixels are not objects

The image panel estimates the share of green-ish pixels. Lighting, season, camera angle and non-vegetation can affect this rough visual cue.
